# UI-переосмысление JAWL Companion (2026-10-30)

## Что просили
Посмотреть текущий UI (`docs/UI_HANDOFF_20261030.md`) и переосмыслить его: красивое, но простое и лаконичное.

## Что осталось прежним
- Единое окно приложения, один порт `2367`, один источник правды (`/api/*` + WS), как в ADR-052.
- Работает только présentation-слой: `desktop/app.html`, `desktop/app.js`, `desktop/app-settings.js`, `desktop/app-scene.js`; ядро и API не менялись.
- Навигация по разделам через те же `data-tab`/`data-section`: Чат, Аватар, Голос, Память, Настройки, Система.
- Компактный HUD, OBS-режим (`?mode=obs`), закрепление, клик-сквозь, режим уменьшенного движения, гардероб VRM.
- Все существующие браузерные/Node-тесты десктопа проходят (124/124).

## Что изменилось в `desktop/app.html`
- **Визуальный язык:** светлая, спокойная теплая гамма вместо тёмной: бумажный фон, белые карточки, мягкие границы, акцент JAWL — мятно-петролёвый (`#5ba07f`). Никаких декоративных градиентов-великанов и лишней блестящей обёртки.
- **Зонирование:** сцена с персонажем Occupies основное место, справа — одна активная панель раздела. В настройках сцена убирается, настройки занимают всю ширину окна.
- **Навигация:** узкая левая плиточная навигация с иконами, активный раздел подсвечивается акцентом. Все разделы по-прежнему открываются в одном окне.
- **Чат:** чистые пузыри сообщений, компактный композитор внизу панели, микрофон и остановка речи рядом.
- **Статус:** одна полоса состояния над сценой (аватар + сенсоры), без дублей и технических ламп.
- **Настройки:** карточки с полями в ряд, поиск по названию/описанию/ключу, аккордеон, одна кнопка «Сохранить». Инженерные группы по-прежнему свёрнуты.
- **Компактный режим:** только сцена + HUD в нижней части, сенсорный статус вынесен за сцену и остаётся читаемым.
- **Доступность:** цели управления не меньше 40×40 px, фокус-рамки, подписи и роли сохранены; `prefers-reduced-motion` respected.

## Что не вшло
- Художественный концепт персонажа (заглушка/иллюстрация) не добавлен: генерация изображения недоступна (аккаунт изображения заблокирован), и текущий VRM-аватар владельца не заменяется скрытно, согласно `docs/CHARACTER_ART_DIRECTION.md`.
- В sandbox не было доступного браузера для живого визуального снимка; проверено статически тестами и структурой DOM.

## Соответствие манифесту UI
Не добавлено новых фреймворков, зависимостей, портов или окон. Количество строк CSS сокращено за счёт удаления старых правил; интерфейс собран в существующем единственном файле `desktop/app.html`.

## Вкладка «Память» (обновлено 2026-11-01)
Слово «память» больше не означает сразу четыре разных вещи. Раздел разложен по
потоку из `docs/MEMORY_OWNERSHIP.md`: **сейчас · восприятие** (буфер секунд),
**было · сенсорная история** (час подробно + моменты до 7 дней, без сырого
медиа), **отбор · Ambient Memory** (наблюдения и кандидаты с доверием) и
**долговременно · память JAWL** (единственный писатель). У кандидата есть
кнопка **JAWL**: она передаёт наблюдение агенту с провенансом и ничего не
пишет; состояние «передано»/«в памяти» показывается честно, а при отсутствии
входа событий JAWL кнопка заблокирована с пояснением. Записи, пришедшие из
неподтверждённых наблюдений, помечены как «наблюдение».
