# Исторический снимок перед консолидацией — 2026-10-10

Не текущие инструкции, не активная очередь и не доказательство сегодняшнего
runtime. Исходный текст сохранён, включая прежние dirty changes и датированные
PASS/FAIL/corrections. Служебная плашка добавлена сверху; line endings
нормализованы в UTF-8 текст, содержание оригинала не пересказано.

Оригинальные относительные ссылки/команды внутри снимков рассчитаны на
**исходные пути** из таблицы, а не новую глубину архивного каталога. Их
не переписывали задним числом. При чтении переходить к текущим документам
через эту карту, не исполнять старые запуск/cleanup/provider инструкции.

`CRANE_VLM_GATE.mixed-encoding.bin` — сохранённые исходные байты документа,
в котором UTF-8 начало было смешано с CP1251 хвостом. Рабочий документ
приведён к UTF-8 без смены benchmark-результатов. Это резервная копия
кодировки, не модель/секрет/исполняемый файл.
