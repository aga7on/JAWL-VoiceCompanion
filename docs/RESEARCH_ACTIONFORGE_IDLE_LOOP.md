# ActionForge — CC0-анимации движения для персонажа (research, 13Oct2026)

Источник: `https://actionforge.app/#clip=idle_loop` (Beta; код © CGStuff,
лицензии библиотек MIT в THIRD-PARTY-NOTICES). Браузерная Mixamo-альтернатива:
выбор клипа на риге, поза/IK/правка, экспорт GLB/FBX, скелетные презеты
(Mannequin, UE4/5, Reallusion, Mixamo), Motion Lab (кривые, стиль, 8 направлений).

**Лицензия анимаций — CC0** (public domain): любые цели, коммерчески, без
атрибуции; большинство клипов — Quaternius (Universal Animation Library).
Клип из ссылки — `idle_loop` (idle-петля). Код инструмента — не CC0, но нам
нужен только экспорт, не его код.

## Зачем это нам (для персонажа)

- A-04: лёгкий idle/listening/thinking/speaking graph; сейчас рот по RMS —
  fallback, базовых idle-петель и жестов нет. ActionForge — источник CC0-клипов
  именно для этого слоя, без лицензионных обязательств.
- OBS/U-09: та же motion-графика для presentation-поверхности; один audio owner
  не меняется, экспорт только клипы.
- Motion Lab может давать стилевые варианты (спокойнее/энергичнее) под будущие
  состояния, но не заменяет нашу физику ткани и не решает арт-подобие.

## Черновой путь интеграции

1. Оффлайн-экспорт `idle_loop` (GLB, in-place, без mesh персонажа) на подходящем
   скелетном презете; сохранить в `runtime/`, не в git (правило репо).
2. Ретаргет на humanoid VRM и печ в VRMA (@pixiv/three-vrm-animation). В репо уже
   есть motion-bake инструменты (`tools/vrm_gen/bake_reference_motions.py`) —
   переиспользовать/сравнить, не дублировать пайплайн.
3. Один клип: playback в `/app` (three-vrm сцена), проверка reduced-motion/off
   из настроек, idle не конфликтует с lip-sync и сценой.
4. Затем graph: idle↔listening↔thinking↔speaking с crossfade; speaking — слой
   верхней части корпуса. Физика ткани — A-03, арт-приёмка/active avatar — A-05,
   отдельно; helper-motion не равно полной физике.

## Ограничения и открытые вопросы

- Экспорт/ретаргет GLB→VRMA на нашем VRM ещё не проверен; неизвестно, насколько
  humanoid-кости Quaternius-рига ложатся 1:1 (ожидаемо нужен ретаргет + клин-ап).
- Не коммитить ассеты и не тянуть внешние сервисы в runtime: только ручной
  оффлайн-экспорт; provenance (источник, дата, хеш) фиксировать по A-06.
- Атрибуция не требуется (CC0), но записываем источник для дисциплины лицензий.

## Первый проверяемый срез (предложение)

`idle_loop` → ретаргет → 1 VRMA → playback в `/app` со скриншотом и проверкой
reduced-motion. Не закрывает A-03/A-04/A-05; только подтверждает путь ассета.
