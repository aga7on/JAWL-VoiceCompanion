# Голосовой playback buffer

## Решение

JSON-envelope JAWL остаётся транспортом ответа. После получения ответа UI
делит текст на короткие фразы и передаёт их в одну отменяемую TTS-очередь.
WebAudio использует bounded jitter-buffer: стартовый запас около 250 мс,
максимально запланированный запас около 850 мс.

## Перебивание

Микрофон и VAD работают параллельно воспроизведению. При подтверждённой речи
пользователя `stopSpeech()` отменяет запрос TTS и останавливает все ещё не
проигранные `AudioBufferSourceNode`. Поэтому уже созданный хвост не должен
продолжать говорить после barge-in.

Это симуляция потоковой речи после полного JSON-ответа, а не token-level
streaming модели. Production-приёмка всё ещё обязана измерить first-audio,
задержку перебивания и отсутствие обрыва при обычном продолжении речи.
