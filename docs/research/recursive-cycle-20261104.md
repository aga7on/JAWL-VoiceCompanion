## Продолжение: визуальная свежесть и защита захвата

Сессия Harness остановилась на Connection error; начатые её изменения сохранены,
локальная проверка продолжена без сброса рабочего дерева. Для внутреннего отказа
визуального клиента добавлены четыре проверки: describe/look × TypeError/TimeoutError
вызываются по одному разу с исходным токеном отмены.

Независимое воспроизведение показало, что top-down захват дисплея обходил
настроенные маски. Исправлено: маски и OCR-области применяются до resize; если
активное чувствительное окно пересекает выбранный дисплей, кадр не возвращается.
Это не проверка всех других видимых окон на дисплее.

Если постоянного visual worker нет, on-demand запрос сравнивает исходный кадр
с повторно полученным из того же источника после инференса. Обнаруженная смена
сцены или невозможность проверки не выдаются за актуальный результат. Проверка
не гарантирует обнаружение всех тонких изменений и добавляет один захват на
такой запрос. Runtime SceneState считает возраст по monotonic, а явно заданный
timeline используется для воспроизводимых тестов. Controlled probe смены сцены
стал `not_observed`, вместо прежнего `observed_present`; 103 targeted tests PASS.
Hardware/live-поведение и качество модели не оценивались. CodeSee валидирован.
