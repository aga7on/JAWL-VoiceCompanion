# agent-desktop: предварительная оценка для JAWL

Источник: https://github.com/vercel-labs/agent-desktop . Прочитаны README,
[Windows](https://agent-browser.dev/desktop/platforms/windows),
[ошибки и восстановление](https://agent-browser.dev/desktop/errors-and-recovery),
[Chromium/Electron](https://agent-browser.dev/desktop/guides/chromium-and-electron).
Это документационный и кодовый обзор; binary не установлен, на ПК не испытан.

Проект предоставляет локальный CLI, MCP stdio и C API для работы с деревом
доступности Windows UIA, а также команды окон и ввода. Модели внутри нет.
Снимок содержит ссылки с привязкой к снимку; предусмотрены stale/ambiguous
ошибки и разделение доставки `not_delivered`, `delivery_uncertain`,
`delivered_unverified`, `delivered_verified` с условиями повтора.

В JAWL `src/jawl_voicecompanion/windows_ui.py` уже есть UIA-наблюдение
foreground окна, ограничение элементов и глубины, fingerprint и проверки
ссылок; `composition.py` подключает его через HostOSExecutor. Текущий click
пытается Invoke, а при исключении сразу делает обычный Click: исключение само
по себе не подтверждает, что первый вызов не был доставлен. Требуется отдельная
регрессия этого контракта; это возможный двойной эффект, а не доказанный live баг.

Возможная польза: изучить scope окна и фоновых приложений, глубину/выбор дерева,
диагностируемые ошибки и явные результаты доставки; сравнить на одинаковых
окнах и задачах. Для Chromium дерево может прогреваться 10–25 секунд согласно
документации; работа с уже запущенным Chromium идёт через UIA, а отдельный CDP
предусмотрен для нового процесса. На Windows UIA подчиняется уровню целевого
процесса и не работает на secure/locked desktop. Это не механизм интерпретации
видео, игрового изображения или аудио: для содержимого без UIA нужны текущие
визуальные и звуковые сенсоры.

Гипотеза для изолированного испытания: существующий UIA против agent-desktop на
одних и тех же owned окнах (Notepad, Chromium/Electron): нахождение элемента,
русский текст, длинное дерево, фоновое окно, stale ref, неоднозначная цель,
отключенный элемент, неизвестный результат действия. Измерить успешность,
задержку, размер контекста и дубли после сбоя; не использовать реальные формы
с побочными эффектами. Интеграция или новая зависимость до результатов не решена.
