# BRIDGE_LOOP.md — правила итеративного цикла с внешними старшими моделями

Активируется, когда владелец просит «ночную автономную работу по цепочке со старшими».
Файл читает агент-исполнитель (DSH). Проектные правила AGENTS.md этого репо остаются в силе;
этот файл их дополняет и не отменяет.

## Роли

- **ChatGPT** (вкладка Firefox) — архитектор и критик валидирует работу, финальный план.
- **LM Arena «Argon»** (вкладка Firefox) — генератор гипотез.
- **Ты (DSH-агент)** — исполнитель: код, тесты, бенчмарки, обновление STATE/TODO/CHANGELOG.
- Мост: `tools/seniors_bridge/connect_seniors.py` (локальный сервер 127.0.0.1:5050) +
  Tampermonkey-воркеры в трёх открытых вкладках Firefox.

## Цикл (повторяется, пока владелец не скажет «стоп»)

1. Выполни текущий план (из чата, из `last_plan.md` или из TODO.md — в приоритете указанного порядка).
2. Каждая итерация = один видимый результат + focused regression (как в AGENTS.md проекта).
3. Обнови `docs/STATE.md`, `TODO.md`, `CHANGELOG.md` (коротко, без противоречащих checkpoints).
4. Из корня проекта запусти: `python tools/seniors_bridge/connect_seniors.py`
   - Скрипт общается со старшими 5–30 минут. НЕ пытайся его «превосходить»: дождись завершения.
5. Читай последнюю строку вывода (`BRIDGE_RESULT: ...`):
   - `DELIVERED_VIA_BROWSER` → новый план уже доставлен тебе сообщением в этой сессии
     (`=== ПЛАН ОТ СТАРШИХ ===`) — работай по нему, файл не нужен;
   - `SAVED_TO_FILE` → прочитай `tools/seniors_bridge/last_plan.md` и работай по нему;
   - `TIMEOUT: ...` → запиши причину коротко в docs/STATE.md, продолжай по приоритету TODO.md,
     за один цикл разрешена только 1 попытка повторного запуска моста.
6. Если в сессию пришло новое сообщение `=== ПЛАН ОТ СТАРШИХ ===` — это официальный план
   следующего цикла; продолжай цикл с шага 1 и не игнорируй шаги обновления файлов.

## Приоритет источников плана

1. Новое сообщение `=== ПЛАН ОТ СТАРШИХ ===` из цепочки моста (самое свежее согласованное).
2. `tools/seniors_bridge/last_plan.md` (тот же контент, но считан с диска).
3. Собственная очередь TODO.md (если мост недоступен весь отведённый срок).

## Жёсткие запреты ночного цикла

- Не запускать второй экземпляр моста (порт 5050) — проверки занятости достаточно.
- Не редактировать `connect_seniors.py` и `tampermonkey/*.user.js`, если план прямо этого не требует;
  после любой такой правки обязателен `python tools/seniors_bridge/connect_seniors.py --selftest`.
- Не отправлять в старшие модели секреты, .env, токены; только STATE/TODO-снимки и тезисы.
- Не прерывать/не убивать браузер, таб-вкладки воркеров и python-сервер моста.
- Не считать ответ Bridge успехом без маркера; не «ускорять» цикл пропуском обновления файлов.
- Не блокироваться на вечном ожидании: TIMEOUT — легальный выход в шаг 5.

## Восстановление (если ночь сорвалась)

Утренний разбор цепочки: `tools/seniors_bridge/last_result.txt` (последний маркер),
`last_plan.md` (какой план был последним), STATE.md/TODO.md (что реально доведено).
Владельцу достаточно прочитать их, чтобы увидеть, где цепочка сорвалась.
