# Seniors Bridge — ночной цикл «DSH ↔ ChatGPT ↔ LM Arena»

## ⚡ v2 — night_autopilot.py (актуальный путь)

`night_autopilot.py` ведёт цикл **сам**, через командный канал (см. ниже), и не зависит
от фазовых воркеров: он САМ читает `main`-текст вкладок, печатает промпты, жмёт отправку,
ждёт маркера конца ответа (`===GPT1_END=== / ===ARGON_END=== / ===PLAN_END===`) и
доставляет план в DSH. Лок `night_autopilot.lock` защищает от двойного запуска.

```bat
python tools\seniors_bridge\night_autopilot.py            :: вся ночь (вкапы до MAX_CYCLES и утро)
python tools\seniors_bridge\night_autopilot.py --once     :: один дымовой цикл (для пробы)
```

Логи/состояние: `night_v2.log`, `extracts/cycleNN_phaseX.md`, `v2_state.json`,
план-дубль при недоступной доставке: `last_plan.md`.
Запуск/стоп браузерного командного сервера: `browser_mcp.py` (порт 5051).

### Доставка в ChatGPT: механизм `?q=` (с 8 ноября 2026)

Набивка композера ChatGPT через execCommand стала ненадёжной. Ввод сломанного пути
заменён на предзаполнение через URL: `https://chatgpt.com/?q=<encoded>` (именно на
ГОЛОМ домене — `chatgpt.com/c/<id>?q=` параметр игнорируется). После предзаполнения
автопилот жмёт Enter (`key`-команда).

**Жёсткий лимит**: encoded-длина URL ≤ ~52К символов. URL с encoded ≥ ~105К
убивает загрузку вкладки ChatGPT (воркер «умирает» до перезагрузки). Поэтому:
- фазовые промпты сжимаются заранее (`snapshot_compact()` в A, `hypotheses_toc()` в C);
- полный текст гипотез агент-DSH читает сам из `extracts/cycleNN_phaseB_argon.md`
  (укказатель добавляется в сообщение phase D).

**Воскрешение вкладки ChatGPT** (если она всё же умерла): воркеры `bridge-console`
именуются по URL страницы, поэтому живую вкладку DSH можно перегнать на chatgpt.com —
её воркер перерегистрируется как `chatgpt`, а после работы его же командой
(`navigate` → `http://127.0.0.1:3080/`) возвращают домой. Но перезапуск
`browser_mcp.py` ОБЯЗАТЕЛЕН перед этим: в его in-memory очереди копятся задания
(включая сценарий-убийцу с гигантским URL), очистного endpoint нет.

**Утренняя гигиена (08.11.2026, проверено):**
- Адресная строка вида `chatgpt.com/?q=%D0%B0...` (=«абв абв …») — это осадок
  тестов предзаполнения («?q»-пустышка), НЕ отправленный в диалог контент.
  Битая вкладка с таким адресом — просто Reload; воркер вернётся сам.
- Вкладка DSH за ночь используется как «мигрирующая» (3080 ↔ chatgpt.com):
  SPA DSH переживает перезагрузки плохо, возможен краш веб-приложения
  (агентная сессия при этом не теряется — план, доставленный после рестарта,
  доходит нормально). Если утро началось с падения DSH-web — перезапуск
  приложения штатен, очередь сообщений автопилота уже «слилась».

`connect_seniors.py` (v1, порт 5050) остаётся как альтернатива/фолбэк — его штатная
установка ниже; v2 требует ТОЛЬКО четвёртый userscript (bridge-console.user.js).

Цепочка одной итерации:
`DSH-агент (работа по плану) → docs/STATE.md+TODO.md → ChatGPT (анализ) → LM Arena Argon (гипотезы) → ChatGPT (итоговый план) → доставка плана в сессию DSH → повтор`.

Оркестратор: `connect_seniors.py` (127.0.0.1:5050, чистый stdlib). Воркеры: Tampermonkey в Firefox.
Правила исполнителя: [BRIDGE_LOOP.md](BRIDGE_LOOP.md). Продолжаются **существующие диалоги** — вкладки:

- ChatGPT: `https://chatgpt.com/c/6aeb2af9-bed4-83ee-a372-8b9165dcedf8`
- LM Arena: `.../c/01a1b69b-9cba-730c-8ec6-fb7770bd6957` (Direct Chat, модель Argon выбрана)
- DSH: `http://127.0.0.1:3080` — открытая сессия (её composer)

## Установка (один раз, ~3 минуты)

1. В Firefox: Tampermonkey → панель → **«Создать новый скрипт»** → очистить шаблон →
   вставить содержимое файла → Ctrl+S. Повторить для всех четырёх (4-й — только для v2-автопилота):
   - `tampermonkey/bridge-console.user.js`   ← ОБЯЗАТЕЛЕН для night_autopilot.py (v2)
   - `tampermonkey/bridge-chatgpt.user.js`   (v1; v2 не пользуется, но пусть стоит)
   - `tampermonkey/bridge-arena.user.js`     (v1)
   - `tampermonkey/bridge-dsh.user.js`       (v1)
   (Быстрый путь: открыть файл по `file:///G:/AI/JAWL-VoiceCompanion-V0.5/tools/seniors_bridge/tampermonkey/bridge-chatgpt.user.js` — Tampermonkey сам предложит установку; если не предложил — путь через «Создать новый». )
2. При первом запросе Tampermonkey спросит доступ к `127.0.0.1` — «Разрешить всегда» (для каждого из 3 скриптов).
3. В консоли каждой вкладки (F12) должно появиться: `[Bridge-...] воркер запущен`.
   Проверка связи: `__bridgeHealth()` в консоле — должен вернуть текущую фазу оркестратора.
4. Вкладки НЕ закрывать; Firefox оставить открытым. В Chrome-настройках «энергосбережения» равнозначная
   мера для Firefox не нужна, но окно можно свернуть на второй монитор (не сворачивать в трей полностью).

## Запуск

- **Актуально (ночь текущий цикл): `python tools\seniors_bridge\night_autopilot.py`** (лог `night_v2.log`).
- v1 (фоловер): `night_start.bat` крутит `connect_seniors.py` (порт 5050, лог `night.log`); `--selftest` для самопроверки.

## Что происходит ночью

1. Воркер ChatGPT забирает снимок STATE/TODO, отправляет его в закреплённый диалог, ждёт ответ.
2. Воркер Arena забирает запрос архитектора → гипотезы Argon.
3. ChatGPT сводит её в план → оркестратор пишет `last_plan.md` и доставляет план в открытую сессию DSH
   (если сессия занята — план уйдёт в очередь/steer штатными средствами DSH).
4. DSH-агент читает сообщение `=== ПЛАН ОТ СТАРШИХ ===`, выполняет итерацию, обновляет STATE/TODO/CHANGELOG
   и сам запускает `connect_seniors.py` — цикл замыкается. `BRIDGE_RESULT: ...` в конце вывода — вердикт шага.

## Что может потребовать человека ночью (редко)

- Капча/лимиты ChatGPT или Arena — вкладка терпеливо повторяет; оркестратор сам продолжит после снятия капчи.
- Если сессия Arena «протухла» и модель сброшена — заново выбрать Argon в Direct Chat (тот же диалог `/c/...`).
- Маркер и последнее состояние моста всегда: `last_result.txt`, `night.log`, `last_plan.md`.
